# Ledger Bootcamp Pilot

A pilot at turning this book into a taught cohort, rather than only a
solitary read — eight sessions, one running set of Ledgerly's own books,
one capstone that produces a real, honest audit instead of a grade.

This directory is the curriculum's *source*. The student handout and
facilitator guide are build artifacts, generated by
[cohort-kit](https://github.com/alpibrusl/cohort-kit) and never committed
— see `../.gitignore`.

## Files

- **`cohort.yaml`** — identity and format: title, session count, cohort
  size, prerequisite.
- **`sessions.yaml`** — the eight sessions: which chapters each draws on,
  what happens live, the exercise or (session 8 only) the capstone
  deliverable, and the checkpoint that tells you it landed.
- **`rubric.yaml`** — the four dimensions the capstone is actually judged
  on, grounded directly in Chapter 15's own checklist and the
  `verify-ledger` skill's own rules. Shown to students from the start, in
  the handout itself — not held back as a surprise.
- **`fixture/`** — the generated books reused across Sessions 3, 4, and 5.
  See `fixture/README.md`.

## The scenario

Every session grounds itself in the same fictional company the book's own
chapters follow: Ledgerly, asked for its seed-round numbers, gets back a
forecast claiming revenue triples in twelve months and runway is eighteen
months. Chapters 7 through 9 spend three chapters taking that sentence
apart — the model's own mechanics check out, but the growth rate driving
the tripling was read off two unusually good months instead of the
business's real history, and the runway number never heard about a hire
that had already been signed. Sessions 3, 4, and 5 hand students the same
trailing year of numbers, generated fresh each time, and ask them to find
both problems themselves rather than read about someone else finding them.

## Build it

```bash
pip install "content-kit-core @ git+https://github.com/alpibrusl/content-kit@main#subdirectory=packages/core"
pip install "cohortkit @ git+https://github.com/alpibrusl/cohort-kit@main"

make cohort-check   # validate sessions.yaml against this book's actual chapters
make cohort-build   # → cohort/build/handout.html, cohort/build/facilitator-guide.html
```

`cohort-check` cross-references every session's chapter list against
`book.yaml` — a chapter renumber in the manuscript surfaces here as a
real check failure, not a stale reference nobody notices.

`cohort-build` passes `--book-path .`, so each session's referenced
chapters are embedded straight from this book's own Markdown — collapsed,
one per chapter, right where that session lists them. A student needs
nothing but the handout itself to read along; no PDF or EPUB has to exist
first, and the book's own text never drifts out of sync with the source.

## CI

The `cohort` job in `.github/workflows/book.yml` runs `make cohort-check`
then `make cohort-build` on every push and pull request, and uploads
`cohort/build/` as a workflow artifact — the same gate the manuscript's own
`build` job runs for the book itself, just for the curriculum instead.
There is no published-handout pipeline wired up yet (the equivalent of
*Prompt to Production*'s `pages` workflow); until one exists, both
`handout.html` and `facilitator-guide.html` are local build artifacts only
(`make cohort-build`). The handout tracks progress in the browser's own
`localStorage`, keyed to wherever it's opened from — so if a Pages
pipeline is added later, students need a stable URL, not a copy of the
file, for a checked-off session to still be there next time.

Instructors collect students' exported progress files (the handout's
**Export progress** button) and aggregate them with:

```bash
cohortkit progress path/to/exports-folder --cohort-dir cohort --out report.html
```

## Status

Pilot. Not yet run with a real cohort. Built the same way, from the same
`cohort-kit`, as the equivalent module for *Prompt to Production* — if
this one holds up too, the same shape is the template for the remaining
two books in the series, *Prompt to Evidence* and *Prompt to Decision*.
