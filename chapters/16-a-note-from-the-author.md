# A Note from the Human Author

> **Afterword**

Every practice in this book — a chart of accounts, a reconciliation, a load-bearing assumption named out loud — exists because a business's finances are not something anyone can simply look at and know. They have to be represented: written down in a form explicit enough that someone who wasn't in the room can check it, argue with it, and catch what the person who built it missed.

That representation is older than any of us. Double-entry bookkeeping is roughly seven hundred years old, invented for the same reason this book keeps returning to: a merchant's memory of a good year is not evidence a lender can act on, and a ledger is. Every convention this book teaches — separating cash from profit, testing a model against a known year, naming the one assumption a forecast actually depends on — is a more recent descendant of that same original move. Make the implicit explicit, so it can be checked by someone other than the person who made it.

An agent changes what's expensive about that move, not whether it's still the right one. Building the model, running the formulas, even flagging that a growth rate looks unusually optimistic — all of that is now fast, in a way it never was for the merchant with the ledger. What hasn't gotten any faster is knowing which assumption to distrust, which number to reconcile against reality before a decision leans on it, which convenient-looking forecast to interrogate harder precisely because it's convenient. That is still work only a person watching for it will do, and it is the actual subject of this book, underneath the spreadsheets.

I have argued elsewhere — at `alpibru.com/manifesto` — that the deeper shift is away from comprehension as the basis for trust and toward verification: not understanding every formula, but confirming the model survives a check that would have caught it being wrong. A known-answer test that a forecasting model visibly passes against last year's real numbers tells you something no amount of nodding along to the formulas ever did. Comprehension was a strategy. It is not the only one, and for most of this book's readers, it was never really available to begin with.

I expect the mechanical parts of this to keep getting faster and more automatic — reconciliation running continuously instead of monthly, sensitivity analysis generated by default instead of requested, a model that flags its own load-bearing assumption before you think to ask. I would be surprised if that happened and the underlying discipline stopped mattering. Explicit assumptions, checked against reality, with someone accountable for the decision built on top of them — that part is not a limitation of today's tools. It is what a trustworthy number has always required, computed by hand or by an agent in a minute.

What doesn't change is where the accountability sits. A model can be right, and the decision built on it can still be yours to own. No amount of automation moves that, and this book was never trying to.

Read what came before as the discipline this moment actually calls for. Not a permanent shape.

— Alfonso Sastre
